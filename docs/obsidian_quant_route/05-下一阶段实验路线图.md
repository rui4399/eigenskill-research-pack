### ours-lite 第一版

不要一开始做复杂旋转。第一版只做 sensitivity-based bit allocation：

```text
S_l = α · activation_norm_l + β · outlier_ratio_l + γ · HessianProxy_l
```

位宽候选：

```text
b_l ∈ {2,3,4,8}
```

目标：

```text
min_{b_l} Σ_l S_l ε_l(b_l)
s.t.      Σ_l n_l b_l <= B
```

实现上可先用 greedy：

```text
从全 INT2/INT3 开始，逐步给收益最大的层升 bit，直到预算耗尽。
```

## 4 周计划：形成论文核心贡献

### 目标

把 ours-lite 升级为正式 EigenSkill-Q：

```text
Sensitivity-Rate-Distortion Guided Mixed-Precision Quantization
```

### 数学主式

```text
min_{b_{l,g}} Σ_{l,g} S_{l,g} σ_{l,g}^2 2^{-2b_{l,g}}
s.t.        Σ_{l,g} c_{l,g} b_{l,g} <= B
```

推导得到：

```text
b_{l,g}^* = clip_B( 1/2 log2( S_{l,g} σ_{l,g}^2 / (λ c_{l,g}) ) )
```

其中：

- $l$ 是层；
- $g$ 是 group/channel/block；
- $S_{l,g}$ 是敏感度；
- $σ_{l,g}^2$ 是旋转或分组后的方差；
- $c_{l,g}$ 是硬件成本；
- $λ$ 用二分搜索满足预算。

### 需要做的 ablation

```text
uniform INT4
uniform INT3
random mixed precision
activation-only sensitivity
Hessian-only sensitivity
activation + Hessian sensitivity
rate-distortion closed-form allocation
rate-distortion + empirical distortion table
```

## 8 周计划：冲会议/期刊初稿

### 目标

形成可投稿版本：

```text

```

### 加入 rotation

候选旋转族：

```text
No rotation
Hadamard
block-Hadamard
Butterfly/Givens structured rotation
TORQ-style two-level rotation for MXFP4
```

目标函数：

```text
min_R tr(ΔW_R R C R^T ΔW_R^T) + ρ Cost(R)
s.t.  R^T R = I
```

实际实现可从 block-Hadamard 开始，不要一开始写复杂 learned rotation。

### 加入低秩残差

结构：

```text
y = Q_b(W)x + A(B^T x)
```

闭式初始化：

```text
E = W - Q_b(W)
E C^{1/2} ≈ U_r Σ_r V_r^T
A B^T = U_r Σ_r V_r^T C^{-1/2}
```

实验变量：

```text
r ∈ {0, 2, 4, 8, 16}
```

### 加入系统测量

至少测：

```text
NVIDIA GPU:
- VRAM
- tokens/s
- latency per token
- dequant overhead

CPU:
- RAM footprint
- tokens/s

可选 ARM/RK3588:
- 如果设备不在身边，先写 planned artifact，不作为主 claim
```

如果没有真实 kernel，只能写 algorithm paper；不能声称系统加速超过 llama.cpp。

## 需要避免的误区

1. 不要再扩大 toy skills 来证明泛化。扩大 8 个业务 skill 到 30 个仍然可能只是更多模板泄漏。
2. 不要先写 C++ kernel。没有算法结果，kernel 没意义。
3. 不要先声称国产硬件支持。没有设备实测就是风险。
4. 不要混淆 PTQ、QAT、runtime quantization。第一版建议主攻 PTQ。
5. 不要只报 accuracy。必须报 memory、latency、calibration size、ablation。

## 最小可执行实验主张

第一篇能成立的最小主张应该是：

```text
在公开小模型上，我们提出 sensitivity-rate-distortion guided mixed-precision PTQ。
相比 uniform INT4/INT3 和 naive mixed precision，它在相同模型大小下更好保持 perplexity 和 reasoning/code accuracy。
该方法可解释、可复现、校准样本少，并能扩展到 rotation 和低秩残差补偿。
```

这比原来的“Eigen-Skill token 触发 O(d) bypass”更稳，也更容易得到导师和审稿人认可。
