# 无泄漏量化策略数据集 v0

日期：2026-06-03

## 目的

旧 v2 skill 数据集有严重 train/eval 泄漏，因此新增一个干净的小型量化策略数据集，用作下一版训练和方法验证起点。


## 说明

这个数据集仍是合成数据，不应直接宣称为论文主 benchmark；它的价值是替代旧泄漏数据，验证量化策略 routing 的训练流程、无泄漏审计、LoRA 训练和小模型输出格式控制。

正式论文仍需加入公开 benchmark：WikiText2/C4、ARC/PIQA/HellaSwag、GSM8K、MBPP/HumanEval、LongBench/Needle 等。
