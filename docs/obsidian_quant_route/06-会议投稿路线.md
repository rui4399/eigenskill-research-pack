## 总体判断

会议也可以，而且对 EigenSkill 当前阶段更现实。原因：

1. 会议允许更聚焦、更快迭代；
2. workshop 可以先验证 idea，拿反馈，再扩成期刊；
3. 系统会议更看重 end-to-end artifact，适合 EigenSkill 的 C++/端侧 runtime；
4. ML 主会更看重算法新颖性和公开 benchmark，适合量化数学主线。

当前最合理策略：

```text
短期：Workshop / AAAI-27 / ASPLOS'27 Sep cycle
中期：ICLR/ICML/NeurIPS 2027 主会
```

## 三条会议路线

### 路线 A：AAAI-27 快速算法稿

目标：2026-07-28 前完成一篇 7-8 页左右的 AI 方法稿。

题目候选：

```text
Sensitivity-Guided Mixed-Precision Quantization for Small and Edge Language Models
```

主贡献压缩成三点：

1. 以 activation covariance / Hessian proxy 定义 layer sensitivity；
2. 用 sensitivity 做 bit allocation；
3. 在 0.5B-2B LLM 上显示同等内存下优于 RTN/GPTQ/AWQ 的精度保持。

最低实验：

- 3 个模型：SmolLM2-360M、Qwen2.5-0.5B、Qwen2.5-1.5B 或 Phi/Gemma small；
- 4 个任务：WikiText/C4 perplexity、ARC/PIQA/HellaSwag、GSM8K、小型 code；
- 4 条 baseline：RTN、GPTQ、AWQ、SmoothQuant；
- ablation：无 sensitivity、uniform bits、random sensitivity、ours。

风险：时间很紧，当前 toy skill 数据不能用作主证据。

### 路线 B：ASPLOS'27 Sep 系统稿

目标：2026-09-09 前做出系统论文。

题目候选：

```text
EigenSkill-Q: A Hardware-Aware Mixed-Precision Runtime for Edge LLM Inference
```

主贡献：

1. quantization skill router：层/通道/KV cache 策略路由；
2. C++ micro-kernel：低秩 residual、mixed-bit unpack、cache-aware layout；
3. 端侧/CPU/GPU 实测：latency、memory bandwidth、energy proxy；
4. artifact 可复现。

最低实验：

- x86 CPU + NVIDIA GPU + 至少一个 ARM/RK3588/手机端或模拟环境；
- FP16 / INT8 / INT4 / mixed precision 对比；
- 真实 runtime latency，不只是 fake quant；
- memory footprint 和 throughput。

风险：系统论文最怕只有算法，没有真实系统工程和 benchmark。

### 路线 C：NeurIPS/ICLR/ICML 2027 主会算法稿

目标：用 3-6 个月打磨一个强算法。

题目候选：

```text
Orthogonal Outlier Redistribution with Sensitivity-Aware Bit Allocation for Low-Bit LLMs
```

主贡献：

1. 数学目标函数；
2. 旋转/混合精度/低秩残差统一框架；
3. 误差界或至少充分的理论分析；
4. 大量 benchmark 与 baseline。

这条最适合最终打顶会主会，但不能用当前 toy skills 直接投。

## Workshop 过渡路线

如果想先吸引人加入，可以投 workshop：

- COLM 2026 workshop：LLM compression / efficient language modeling / interpretability 相关；
- NeurIPS 2026 workshops：Efficient ML、ML and systems、model compression、ML for systems；
- MLSys/ASPLOS affiliated workshop：MLArchSys、ML for Systems、efficient inference 等。

Workshop 稿件可以更像 vision + preliminary results：

```text
EigenSkill-Q: Reframing Skill Routing as Quantization Policy Routing for Edge LLMs
```

但主文必须诚实写：当前 8-skill demo 存在 train/eval leakage，只是动机，不是最终结果。

## 最推荐排序

1. 现在到 2026-06-23：准备 workshop short paper，快速拿外部反馈。
2. 现在到 2026-07-28：如果实验能快速补齐，冲 AAAI-27；否则不要硬投。
3. 现在到 2026-09-09：主攻 ASPLOS'27 Sep cycle 的系统版本。
4. 2026 下半年到 2027：扩展成 NeurIPS/ICLR/ICML 主会算法版本。
5. 被会议拒稿后，扩展实验和理论，转 TNNLS/Neural Networks/Information Sciences。
