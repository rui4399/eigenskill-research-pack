## 关键结论

1. 当前 v2 结果不能作为论文泛化证据：eval 中 1339/1440 与 train 完全重复。
2. `99.93% hybrid exact` 是工程演示，不是量化算法贡献。
3. 更强论文方向是：以 Hessian/activation covariance 加权误差为核心，设计可解释的旋转、位宽分配、低秩残差补偿和 KV cache 量化方法。
4. skills 如果保留，应改成“量化校准技能/层级决策技能”，而不是家居命令、JSON 修复这类低熵 toy tasks。
5. 2025-2026 最新量化主线显示：HARP/TORQ/ButterflyQuant 代表结构化旋转，ARHQ/SERQ/pQuant/NanoQuant 代表低秩或高精度残差分支，Q-Palette/RAMP 代表 bit allocation，MicroMix/FP4/NVFP4 代表硬件格式感知量化。
6. v2 训练包已经完成并通过本地 package 校验，但只能作为工程 PoC；下一步训练必须改为无泄漏量化策略 skill。
7. `eigenskill_quant_v0` 已生成，train/eval/test exact/input overlap 均为 0，并完成 0.3 epoch smoke LoRA 训练。

## 推荐主线

```text
EigenSkill-Q: Sensitivity-Rate-Distortion Guided Mixed-Precision Quantization for Edge Large Language Models
```

核心公式：

```text
min_{b_{l,g}, R_l, P_l} Σ_{l,g} D_{l,g}(b_{l,g}, R_l, P_l)
s.t.                    Σ_{l,g} M_{l,g}(b_{l,g}, P_l) <= B
                        R_l^T R_l = I
```

首版应先落地：

```text
sensitivity score + rate-distortion bit allocation + public benchmark + no-leak audit
```

再扩展：

```text
orthogonal rotation + MXFP4/NVFP4 format-aware objective + low-rank residual micro-kernel + KV cache policy
```
