# 2025-2026 最新量化数学方法

日期：2026-06-03

这份笔记专门回答一个问题：如果 EigenSkill 要冲国际期刊/会议，尤其偏数学和人工智能模型量化方向，应该追哪些最新方法，而不是继续堆低熵业务 skills。

## 一句话结论

当前最值得押的方向不是“更多业务 skill”，而是把 EigenSkill 改写成 **量化策略路由器**：

```text
EigenSkill-Q = sensitivity estimation + rotation selection + mixed-precision allocation + residual compensation + hardware-format-aware quantization
```

也就是让 skill 表示“某层/某通道/某激活子空间应该采用哪种量化处理”，而不是表示“开灯、JSON 修复、字段抽取”等业务动作。

## 1. 旋转/子空间方法：EigenSkill 最自然的数学入口

### 1.1 基本等价变换

Transformer 线性层满足：

```text
y = W x
```

若 $R$ 是正交矩阵，$R^T R = I$，则：

```text
y = W x = W R^T R x = W' x'
W' = W R^T
x' = R x
```

全精度下函数不变；量化后不再等价：

```text
\hat y = Q_b(W R^T) Q_b(Rx)
```

所以目标不是证明旋转不改变模型，而是找到让量化误差更小的旋转：

```text
min_{R \in O(d)} E_x || W x - Q_b(W R^T) Q_b(Rx) ||_2^2
```

如果先只做权重量化：

```text
min_{R \in O(d)} E_x || (W R^T - Q_b(W R^T)) R x ||_2^2
```

设 $C = E[x x^T]$，令 $\Delta W_R = W R^T - Q_b(W R^T)$：

```text
D(R,b) = tr(\Delta W_R R C R^T \Delta W_R^T)
```

这就是 EigenSkill-Q 应该继承的“特征/子空间”数学，而不是原先强行要求 $W e_s \approx \lambda e_s$。

### 1.2 HARP：固定 Hadamard 已经不够

HARP 的关键点：

- 固定随机 Hadamard 旋转可以降低 incoherence，但不能适配层、校准分布和量化器；
- HARP 用结构化、两侧、可学习的正交 processor 替代固定 RHT；
- 旋转由 sparse butterfly-like block-orthogonal stages 组成，兼顾可学习性和效率；
- 支持非 2 的幂维度。

对你的启发：EigenSkill-Q 的 `rotation_select` 不应该只在 Hadamard / 不旋转之间二选一，而应学习或搜索一个结构化旋转族：

```text
R_l(\theta) = \prod_{t=1}^{T} B_{t}(\theta_t)
```

其中 $B_t$ 可以是 Givens / Butterfly / block-Hadamard 结构。目标函数：

```text
min_{\theta_l} D_l(R_l(\theta_l), b_l) + \rho \cdot Cost(R_l)
```

这里 $Cost(R_l)$ 要包括额外旋转开销、cache 访问和 kernel 融合难度。

### 1.3 ButterflyQuant：连续 Givens 参数化

ButterflyQuant 的数学优势在于：

```text
R(\theta) = \prod_{k} G_k(\theta_k)
```

每个 $G_k$ 是二维 Givens rotation：

```text
G(\theta)=
[ cos\theta  -sin\theta
  sin\theta   cos\theta ]
```

优点：

1. 正交性天然成立；
2. 参数量约 $O(n \log n)$；
3. 可以梯度优化；
4. 比固定 Hadamard 更能适配不同层的 outlier pattern。

这适合写成 EigenSkill-Q 的结构化旋转模块。

### 1.4 TORQ：MXFP4 不是普通 INT4

TORQ 的重要性在于它把旋转和 MXFP4 格式绑定起来。MXFP4 是 block floating point：一个 block 中多个 FP4 值共享 scale。它的问题不是单个值 round error，而是两类结构失衡：

```text
inter-block variance imbalance
intra-block codebook utilization imbalance
```

对应目标可以写成：

```text
min_R  \alpha \cdot VarBlockEnergy(RX)
      + \beta  \cdot CodebookCollapse(RX)
      + \gamma \cdot QError_MXFP4(RX)
```

TORQ 还使用 Schur-Horn theorem 解释能量重分配，这是很适合国际论文的数学切入点。

EigenSkill-Q 可写成：

```text
rotation skill = select {Hadamard, block-Hadamard, Butterfly, TORQ-style two-level rotation}
conditioned on {activation covariance, block variance, codebook occupancy, hardware format}
```

## 2. MXFP4/NVFP4：必须进入主线

如果你目标是国际期刊/会议，现在不能只谈 INT4。2025-2026 的硬件趋势已经明显转向 FP4 / microscaling。

### 2.1 Block-floating quantization

对一个 block $B = \{z_i\}_{i=1}^m$，block FP4 通常可写为：

```text
\hat z_i = s_B \cdot c_i
c_i \in \mathcal{C}_{FP4}
```

误差：

```text
E_B = \sum_{i \in B} (z_i - s_B c_i)^2
```

如果 $s_B$ 被粗糙地限制为 2 的幂，例如 MXFP4 的 E8M0 scale，会出现 scale quantization error。NVFP4 改用更细的 E4M3 scale，并加第二级 FP32 per-tensor scale：

```text
\hat z_i = s_{tensor}^{FP32} \cdot s_{block}^{E4M3} \cdot c_i^{E2M1}
```

这给你一个很好的数学方向：

```text
min_{R, partition, s} \sum_B \sum_{i \in B} ( (Rz)_i - s_B c_i )^2
```

同时加入硬件约束：

```text
|B| \in {16, 32},  s_B \in E8M0/E4M3,  c_i \in E2M1
```

### 2.2 MicroMix：混合 microscaling 格式

MicroMix 的核心不是单纯量化算法，而是 algorithm + GEMM kernel co-design：

```text
format_i \in {MXFP4, MXFP6, MXFP8}
```

优化可以写成：

```text
min_{f_i} \sum_i S_i \cdot \epsilon_i(f_i)
s.t.      \sum_i cost(f_i) \le B,
          f_i \in {4,6,8}
```

这里 $S_i$ 可以是 activation norm、Hessian trace、outlier ratio、perplexity sensitivity 或任务敏感度。

对 EigenSkill-Q 的意义：你不需要一开始就发明全新格式；更现实的是做 **format-aware routing**：同一层不同通道/块选择 MXFP4/MXFP6/MXFP8 或 INT4/INT8。

## 3. Hessian/曲率方法：过拟合之外最重要的泛化证据

### 3.1 二阶近似

令量化扰动为：

```text
\Delta W = \hat W - W
```

损失变化二阶近似：

```text
\Delta L \approx \frac{1}{2} vec(\Delta W)^T H vec(\Delta W)
```

如果 $H$ 过大，说明该方向对 loss 很敏感，应该给更高精度或补偿分支。

### 3.2 ARHQ：activation residual Hessian

ARHQ 的思想很适合你原来的“旁路”直觉，但它更严谨：

1. 激活也会被量化，产生 activation residual；
2. 用 residual 构造 input-side residual Hessian $G_x$；
3. 对缩放后的矩阵做截断 SVD：

```text
W G_x^{1/2} \approx U_r \Sigma_r V_r^T
```

敏感方向进入高精度低秩分支：

```text
W \approx Q_b(W - W_{hp}) + W_{hp}
W_{hp} = U_r \Sigma_r V_r^T G_x^{-1/2}
```

这比 $W e_s = \lambda e_s$ 强很多，因为它直接回答：哪些方向在低比特激活误差下最脆弱。

### 3.3 HESTIA：Hessian-guided differentiable QAT

HESTIA 适合 1.58-bit / ternary QAT 主线。它不是直接 hard round，而是用温度控制的 softmax relaxation：

```text
q(w; \tau) = \sum_{k} p_k(w,\tau)c_k
p_k = softmax(-||w-c_k||^2 / \tau)
```

随着训练推进，$\tau \to 0$，软量化逐渐硬化。

Hessian trace 用来控制不同 tensor 的退火速度：

```text
\tau_l(t) = \tau_0 \cdot g(t, Tr(H_l))
```

敏感层退火更慢，避免早期离散化造成不可逆损伤。

## 4. 混合精度分配：EigenSkill-Q 的最核心 skill

### 4.1 统一优化式

最适合你论文的主式：

```text
min_{b_l, R_l, P_l} \sum_l D_l(b_l, R_l, P_l)
s.t.                  \sum_l M_l(b_l, P_l) \le B
                      \sum_l T_l(b_l, R_l, P_l) \le T_{max}
                      R_l^T R_l = I
```

其中：

- $b_l$：位宽或格式；
- $R_l$：旋转/预处理；
- $P_l$：低秩补偿、分组、scale policy 等策略；
- $D_l$：Hessian/activation weighted distortion；
- $M_l$：显存/模型大小；
- $T_l$：kernel latency / memory bandwidth / dequant cost。

### 4.2 Lagrangian 形式

```text
\mathcal{J} = \sum_l S_l \epsilon_l(b_l)
            + \lambda (\sum_l n_l b_l - B)
```

最优分配满足边际收益相等：

```text
S_l [\epsilon_l(b_l) - \epsilon_l(b_l+1)] \approx \lambda n_l
```

直觉：多给 1 bit 的收益越大，越应该保高精度。

### 4.3 Fractional-bit / Q-Palette

Q-Palette 的重要性在于把 bit allocation 和 rate-distortion 联系起来。若旋转后权重近似 Gaussian，高斯率失真理论给出：

```text
D_i(R_i) \approx \sigma_i^2 2^{-2R_i}
```

在总 bit 预算下：

```text
min_{R_i} \sum_i \sigma_i^2 2^{-2R_i}
s.t.      \sum_i R_i \le B
```

Lagrange 推导：

```text
R_i^* = \frac{1}{2}\log_2 \frac{\sigma_i^2}{\lambda}
```

若加入 sensitivity：

```text
D_i \approx S_i \sigma_i^2 2^{-2R_i}
R_i^* = \frac{1}{2}\log_2 \frac{S_i\sigma_i^2}{\lambda}
```

这可以成为 EigenSkill-Q 的数学亮点：不是启发式选 bit，而是从 rate-distortion + sensitivity 推出位宽分配。

### 4.4 RAMP：RL 版 mixed precision

RAMP 用策略学习每层 bit-width：

```text
\pi_\phi(b_l | z_l)
```

其中 $z_l$ 包含 activation statistics、weight properties、structural descriptors。奖励：

```text
r = -PPL(\{b_l\}) - \lambda \max(0, Mem(\{b_l\})-B)
```

这适合做 baseline，但如果你想发数学更强的稿子，最好不要只做 RL，因为审稿人会问：为什么不是黑箱策略搜索？你的优势应该是给出可解释的敏感度函数和可证明分配规则。

## 5. 低秩残差补偿：把“旁路”改写成可发表形式

原本的 $O(d)$ eigen bypass 很容易被非线性和分布偏移击穿。更稳的旁路是：

```text
W \approx Q_b(W) + A B^T
rank(A B^T) = r \ll d
```

优化：

```text
min_{A,B} E_x || (W - Q_b(W) - A B^T)x ||_2^2
```

若有 $C = E[xx^T]$：

```text
min_{A,B} tr((E - A B^T) C (E - A B^T)^T)
E = W - Q_b(W)
```

白化后：

```text
E C^{1/2} \approx U_r \Sigma_r V_r^T
A B^T = U_r \Sigma_r V_r^T C^{-1/2}
```

这就是闭式低秩补偿。它比“skill token eigenvector”更像能过审的数学主张。

SERQ、ARHQ、pQuant、NanoQuant 都在不同程度上支持这条线：

- SERQ：单个低秩补偿矩阵，服务 W4A4；
- ARHQ：用 activation residual Hessian 找高精度低秩分支；
- pQuant：1-bit 主分支 + 高精度敏感分支；
- NanoQuant：低秩二值因子 + ADMM 初始化，把极低比特推到 sub-1-bit。

## 6. KV cache 量化：最适合系统会议

KV cache 量化目标不是压模型权重，而是压长上下文推理中的动态内存：

```text
K_t, V_t \in R^{h \times d_h}
```

注意力误差主要来自：

```text
softmax(q^T K / \sqrt{d_h}) V
```

如果量化 $K,V$：

```text
\Delta a \approx J_{softmax} \cdot q^T \Delta K
\Delta y \approx \Delta a \cdot V + a \cdot \Delta V
```

这说明 key 的误差会先经过 softmax Jacobian 放大，再影响 value 加权和。

SAW-INT4 的重要结论：真实 serving 里，复杂离线高精度方法未必最优；paged memory、regular access、fused attention 这些系统约束会改变最优解。它发现 token-wise INT4 + block-diagonal Hadamard rotation 是更现实的 accuracy-efficiency tradeoff。

OSCAR 更进一步把 KV cache 量化写成 attention-aware spectral covariance 问题：离线估计 K/V covariance，生成固定旋转和 clipping threshold，在线用 INT2 存长历史 KV，同时保留一小段 BF16 recent window。这对 EigenSkill-Q 很关键，因为它说明旋转目标不能只最小化 raw reconstruction error，而要最小化 attention 实际使用方向上的误差。

TurboQuant / PolarQuant 则提供更数学化的路线：把流式 KV 向量看成在线 vector quantization，目标接近 Shannon rate-distortion lower bound。PolarQuant 通过极坐标变换避免传统 block quantizer 需要存很多 scale/normalization 常数，TurboQuant 再用 Quantized Johnson-Lindenstrauss residual correction 改善内积估计。这条线适合写理论，但实现复杂度比普通 INT4 KV cache 高。

对 EigenSkill-Q：

```text
kv_policy skill = choose quant granularity + rotation + scale update policy
conditioned on {context length, head sensitivity, cache layout, serving batch pattern}
```

## 7. 过拟合问题应该怎么接入量化论文

当前 v2 skill 训练严重泄漏，不能作为主实验。但它暴露了一个有价值的问题：如果 skill 是低熵模板任务，模型很容易记忆。

新的 skill 设计应改成量化误差模式：

| 新 skill | 不是业务动作 | 而是量化决策 |
| --- | --- | --- |
| `rotation_skill` | 不代表某个任务 | 选择旋转族和参数 |
| `bit_skill` | 不代表文本类别 | 选择 bit-width / format |
| `residual_skill` | 不代表 JSON 修复 | 选择是否添加低秩残差 |
| `kv_skill` | 不代表路由命令 | 选择 KV cache 量化策略 |
| `outlier_skill` | 不代表实体抽取 | 判断 activation/weight outlier 类型 |
| `task_sensitivity_skill` | 不代表业务任务 | 估计 reasoning/code/math 对量化的脆弱度 |

实验上必须做：

```text
train/calibration tasks != validation tasks != test tasks
prompt templates disjoint
models disjoint if声称 transfer
calibration samples <= 128/256/512，公开固定 random seed
```

## 8. 最适合写成论文的三个命题

### 命题 A：Sensitivity-Rate-Distortion Bit Allocation

提出一个可解释分配公式：

```text
b_{l,g}^* = clip_{\mathcal{B}} \left(
  \frac{1}{2}\log_2 \frac{S_{l,g}\sigma_{l,g}^2}{\lambda c_{l,g}}
\right)
```

其中：

- $S_{l,g}$：Hessian/activation/task sensitivity；
- $\sigma_{l,g}^2$：旋转后组方差；
- $c_{l,g}$：硬件成本；
- $\lambda$：预算拉格朗日乘子。

### 命题 B：Hardware-Format-Aware Orthogonal Rotation

不是泛泛地学习 $R$，而是针对 format 设计：

```text
min_{R \in \mathcal{R}} \sum_B QErr_{format}( (RX)_B )
```

其中 format 可为 INT4、MXFP4、NVFP4、FP8，$\mathcal{R}$ 是 Hadamard/Butterfly/block-orthogonal/Givens 混合族。

### 命题 C：Residual Micro-Kernel Compensation

把原本的 C++ 旁路改成低秩残差 kernel：

```text
y = Q_b(W)x + A(B^T x)
```

复杂度：

```text
Q_b(W)x: low-bit GEMM
A(B^T x): O(rd + rd_out), r << d
```

这比“直接跳过 GEMM”可信，因为它仍然服务任意输入，不依赖 skill token 完全落在不变子空间。

## 10. 不建议再主打的点

1. 不主打 $W e_s \approx \lambda e_s$ 导致 $O(d)$ 推理。这个点太容易被 LayerNorm/SwiGLU/residual/attention 反驳。
2. 不主打家居/JSON/packet skill 准确率。当前数据泄漏太重，且任务低熵。
3. 不主打“国产硬件全适配”。没有真实昇腾/RK3588/NPU kernel 前，这只是愿景。
4. 不主打“群体大模型物理形态”。这可以作为 vision，不适合第一篇严肃量化论文主贡献。
